**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 multiplayer (build v7.96)

Two crash fixes, from player reports. Both were timing problems in the game's own code that show up more often on PC. After the update, the launcher relinks the multiplayer game by itself, which takes a few seconds.

- **Custom-game lobby:** switching characters quickly could crash the game.
- **Friends list:** the game could crash while the Friends list was open.

## Launcher

- **The update progress is now in the bottom bar:** one line such as `UPDATE IN PROGRESS - 12/55 (21%)` with a bar under it, in the middle of the bar. The bar now matches the step count.
- Window titles now say **Unofficial Port**: the launcher's and the games'.
