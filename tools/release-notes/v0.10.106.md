**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 2 multiplayer

- **The import is C++ now, and much faster.** The Uncharted 2 import (`u2mp\bin\u2import.exe`) no longer needs
  Python. On our test PC a full fresh import went from about 9 minutes to about 1.5 minutes. Every file it makes is
  exactly the same as before; your existing import is kept, and the update only redoes the few small steps whose
  converter changed.
- **The multiplayer code inside the game was rewritten** from written descriptions of what it does, so it no longer
  carries code taken from the PS3 game. Each part was checked against the previous version with automatic tests
  (thousands of cases, all equal); nothing should look or play differently.
