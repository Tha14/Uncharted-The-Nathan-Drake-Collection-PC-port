**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Launcher

The launcher is moving to its own native code, one piece at a time. Nothing changes in how it looks or works.

- **Add to Steam** (Advanced -> STEAM) now runs on the launcher's own native code. Your existing Steam entries are found and updated as before, your Steam list is backed up first, and the library pictures still come from your own game files.
- **Freeze reports:** when a game stops responding, the report of what every thread was doing is now written by the same native code.
- Developer-only tools are no longer part of the download.
