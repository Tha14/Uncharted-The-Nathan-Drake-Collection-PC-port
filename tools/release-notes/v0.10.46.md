**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Launcher

The launcher keeps moving to its own native code. Nothing changes in how it looks or works.

- **Settings now run on the launcher's native code:** the launcher's settings, each game's settings and the Quick Setup presets are read and saved by it, in the same files as before. Your settings carry over as they are.
- **Memory tracking for long sessions:** each time a game runs, `memory-<date>-<time>.csv` is written next to its log (in `analysis\<game>\`), one line every 10 seconds: the game's memory, handles and threads, and your PC's free memory. If a game gets slower or crashes after a long session, attach this file to your report.
- **Quick Setup:** only the preset you chose is highlighted now. The recommended one was highlighted too.
