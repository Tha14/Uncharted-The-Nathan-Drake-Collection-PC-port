**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **Fixed: "No connection found" when playing online (0.10.97 and 0.10.98).** The launcher put the file with your session value (`u3-session.key`) in the wrong folder, so the game could not sign in to the server. It now goes where the game reads it. Start the game from the launcher once after updating.
- **Multiplayer build v7.127**: more parts of the multiplayer helper were reimplemented from scratch in C++ (the online profile seal, the invite messages, the network bit packing, the XP thresholds, the Records and time-limit rows, deleting a LAN profile and more). They behave exactly as before; if something in these areas looks different, please send your `boot.log`.
