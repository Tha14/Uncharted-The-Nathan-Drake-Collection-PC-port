**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **The import runs without Python.** The importer itself is now `u3import.exe`, and the last Python step (the HUD
  weapon-mod icons) is C++ too. The weapon-mod icons of the in-match HUD keep their two largest mip levels, as sharp
  as on PS3.
- **Map fixes are part of the level converter.** The normal-map blend, gloss and stripe fix (map-colors2) now runs on
  every level as it is converted, instead of as a separate patch for a fixed list of maps.
- **Multiplayer build v7.212**: we're implementing some remaining functions of the multiplayer helper in C++ (the match
  start and its countdown, the matchmaking vote page, the party list, following a friend into a party, the online room
  messages, respawning, the animation state sent to other players, the Cinema HUD and the kill rewards). They behave as
  before; if something in these areas looks different, please send your `boot.log`.
- **Known issue:** on Airstrip, a second control tower and a piece of wall show next to the real ones. The old fix for
  it no longer fits the current level converter and is being redone inside the converter.
- **The update rebuilds part of the Uncharted 3 multiplayer import** (the converters changed), which takes a while once.
