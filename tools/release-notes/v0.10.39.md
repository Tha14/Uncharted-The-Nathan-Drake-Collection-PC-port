**Uncharted: The Nathan Drake Collection** PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Uncharted 3 online

- **The game signs in with the launcher's RPCN account again.** When an Uncharted 2 multiplayer import was ready, the launcher dropped the RPCN sign-in it hands to Uncharted 3. The game then used its own old settings and showed the old L2 RPCN button.

## Uncharted 3 multiplayer maps (overlay recipe 1.12.0)

0.10.38's map lighting fix (by 33martyr) is now limited to two maps. After the update, the launcher reapplies the multiplayer import by itself.

- **London Underground:** the library no longer has a bright floor, dark walls and hard light shafts.
- **Fort:** the stone stairs no longer look like chrome, and the cream plaster walls use the PS3 colour.
- **The other 16 maps that 0.10.38 changed are put back exactly as they were before it.** The import restores them from the backup it made then.
