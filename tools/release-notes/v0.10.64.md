**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Launcher updates

The update installer moves to the launcher's native code. Updating works as before.

- **Installer on native code:** after an update downloads, a small native program installs it: it waits for the launcher to close, swaps the files, puts the old version back if anything goes wrong, keeps your own files (ReShade, notes, a game folder inside the port) and starts the launcher again.
- **Cleaner updates:** files an older version installed that a newer one no longer has are now removed even when their whole folder is gone (for example an old multiplayer build); your own files in those folders are kept.
