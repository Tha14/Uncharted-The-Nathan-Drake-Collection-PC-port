**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Co-op fixes and faster updates

- **Co-op checkpoint ring**: should be red again, as on PS3 (it was white).
- **Grabbed player**: the fist icon on the blue ring should be back. The player's name turning blue is still being traced: if you get grabbed, please send your `boot.log` (lines starting with `U3MP grab:`).
- **Solo co-op, Monastery church key**: still resets when you let go. Hang on the first key, let go, wait two seconds and send `boot.log` (lines starting with `U3MP mk03:`) to help find the cause.
- **Faster updates**: an update now reruns only the import steps that really changed (0.10.84 reran the whole import by mistake).
