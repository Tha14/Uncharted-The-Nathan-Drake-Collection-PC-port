**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Party joins and joining a match in progress

- **Joining a party**: if the join doesn't put you in your friend's party, the game now asks once more for a fresh party, and otherwise tells you "Unable to join party" at once instead of waiting 20 seconds. A join that was never answered no longer blocks every later join in the same session.
- **Joining a friend's Custom Game in progress**: the join now follows the friend's match from wherever the server put you, so the late join can start.
- **As on PS3**: a friend who is in a Find Game match can't be joined (you are told at once); a friend in a Custom Game can, unless that match no longer takes late joiners (Hunter, or late in a match), in which case you stay in the party.
- **Hosts**: a player whose join failed is no longer kicked over and over in the background.
- Still being worked on: if joining fails, please send both players' `boot.log` files; they now record every step.
