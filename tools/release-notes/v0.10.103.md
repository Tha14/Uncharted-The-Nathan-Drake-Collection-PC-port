**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **The import is now C++ from start to finish.** Every level, character, weapon, sound bank, DC module and map fix the
  import makes from your PS3 and PS4 files is built by `u3fix.exe`; the Python converters are gone (only the HUD mod
  icon step still uses Python). All of it was checked byte for byte against the previous builds.
- **All maps and characters are built with the latest converter.** Its fixes that used to be separate patches now
  happen inside the conversion of every level: PS3 level flags, lightmap flags of vertex-lit pieces, degenerate
  collision triangles (the Borneo co-op freeze), detail / height / glow / tint textures, blend-map direction and source,
  spec masks, water materials, and the London tunnel light probes (the white player in North Atwood).
- **Multiplayer build v7.211**: more of the multiplayer helper reimplemented in C++ (respawn, packet headers, Find Game
  tables, lobby and party lists, leaving multiplayer, co-op weapons, NetInit, the LAN room server, the emblem compositor,
  missions, the anim decoder and the boosters list). They behave exactly as before; if something in these areas looks
  different, please send your `boot.log`.
- **The update rebuilds the Uncharted 3 multiplayer import** (the converters changed), which takes a while once.
