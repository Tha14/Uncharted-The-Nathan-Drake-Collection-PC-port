**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **Crash after players join or leave, or after a few rounds**: the game closed with "Allocation failed ... Wrapped Malloc" in `boot.log`. The game's network memory was only 343 KB (the PS4 version has no multiplayer); it is now 16 MB. This may also be why a player joining a match in progress sometimes never appeared.
- **Freeze guard**: the particle-job wait from 0.10.90 works as before.
- Still being worked on: in some co-op matches the other players cannot move and see no enemies (the round start does not reach them), and a GPU crash in one match. If it happens to you, please send every player's `boot.log`.
