**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Lab maps removed, joining friends mid-match, same match data on every PC

- **Lab maps are gone**: the update removes them from your import and they are never imported again (from your PS3 data or the server). The Lab playlist no longer shows in Find Game; the other modes and maps are unchanged.
- **Joining friends**: you can join a friend's Custom Game while it's in progress. A locked party now refuses you at once, as on PS3, and "Joining Party..." no longer hangs: it gives up after about 20 seconds.
- **Same match on every PC**: the game-mode, map and playlist tables are now built in the same order on every PC. Before, a player whose import missed a step could load a different mode and map than the host (for example TDM London instead of Co-op Monastery) and crash. If the host's mode still doesn't match yours, the game now refuses to start instead of loading the wrong map.
- **Custom Game**: Shambhala's competitive map no longer goes missing from the map list after an update.
- **Import**: fixed the last import step failing on some PCs ("netgame-order-119").

After this update the import runs again on its own to apply these changes; both players need 0.10.83 to play together.
