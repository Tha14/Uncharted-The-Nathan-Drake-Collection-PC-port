**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **Freeze in co-op and matches**: on some PCs the game could freeze a few minutes into a match after the log showed `jobCounterSetupPreupdate == 0 ... SetupPreupdate jobs still running`. The game now waits for those particle jobs to finish, (on PS4 they were always done by then) instead of starting new ones on top. If it ever has to wait, `boot.log` says "particle jobs still running at the renderer's check: waited N ms"; please send that log if a match still freezes.
- **Joining friends who closed the game**: a friend whose game was closed, crashed or was killed no longer keeps showing as "in Uncharted 3" while their launcher is open, so you aren't left waiting 20 seconds for a join nobody can answer.
- **Import**: three import steps (Lab removal, RPCN page removal, netgame order) now run as a small built-in program instead of scripts. They give exactly the same result; the next update just checks them again, which takes seconds.
