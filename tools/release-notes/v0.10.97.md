**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer

- **Multiplayer build v7.118**: 19 more small parts of the multiplayer helper were rewritten from scratch in C++ (menu tabs, lobby buttons, map vote, rank badges, weapon rows and preview, profile names, the "last game" line, co-op missions, Elimination late join and more). They behave as before; if something in these areas looks different, please send your `boot.log`.
- **Online**: one value the helper needs to reach the session server is no longer shipped with the port. The launcher now takes it from your own decrypted PS3 1.19 EBOOT (or from the multiplayer files already on your PC) the first time it starts. You do not have to do anything. If Find Game or invites stop working after this update, start the game from the launcher once more and send your `boot.log`.
