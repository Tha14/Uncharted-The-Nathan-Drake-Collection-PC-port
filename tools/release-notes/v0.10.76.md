**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer: matches line up with PS3, Custom Game fix, online program

- **Custom Game starts what you picked**: hosting a Custom Game could start a different match than the one shown in the lobby (for example Co-op Adventure chapter 3 starting Team Deathmatch on Yemen). The host's game now starts the lobby's choice.
- **Same match list as PS3 1.19**: the multiplayer import rebuilds the match list from your own PS3 online data, in PS3's order and with PS3's rules (271 matches, including Classic on all 24 maps). A match chosen by an RPCS3 player now means the same match on PC, the base for crossplay. Your import updates itself on the next launch; matches that existed only on PC are gone.
- **Every Custom Game entry reachable**: Shade Survival's later maps, Co-op Adventure Fort and Lab-37 TDM now show up in Custom Game.
- **Online part as its own program**: the online sign-in runs as a small background program the launcher starts by itself; it keeps a running game's connection if you close the launcher. Uncharted 3 and Uncharted 2 can each use their own account server (MULTIPLAYER tab, Account Server); games on the same server share one sign-in.
