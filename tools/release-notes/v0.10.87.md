**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Launcher updates come first

- **Less waiting on updates**: with automatic updates on, the launcher installs a new version of itself before it updates your multiplayer import, so the import is updated once, for the newest version, instead of twice.
- If a new launcher version comes out while an Uncharted 3 import update is running, that import update is stopped, the launcher updates, and the import update starts again. Your current multiplayer files are not touched while this happens. A first-time import still finishes first.
