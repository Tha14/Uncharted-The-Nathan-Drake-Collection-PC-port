**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Co-op fixes: offline matches, Airport kill sound

- **Offline matches no longer crash**: since 0.10.66, any match started without an RPCN sign-in (LAN Party, co-op Splitscreen) crashed while loading. Fixed.
- **Airport co-op**: the sound bank with the kill chime (and the assist and hit-marker sounds) now loads on Airport too, as on PS3, so kills should chime there like on every other map.
- **Co-op adventures**: `boot.log` now records each co-op stage change, so a freeze can be traced to the exact part of the map. If your game freezes, please send `boot.log` and the `hang-*.txt` file next to it.
- **Solo co-op**: the Custom Game map row counts its entries like PS3's Solo Co-Op Patch; `boot.log` also gets `U3MP mk02` lines that will help with the Monastery church key, which still resets when you let go in solo play.
