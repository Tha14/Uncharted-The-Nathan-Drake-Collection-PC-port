**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer (build v7.112)

- **Co-op diagnostic**: in some co-op matches with three players, the other players could not move and saw no enemies, because the round start never reached them. This build writes to `boot.log` which game events each PC sends to and receives from each player ("U3MP ev" lines). Nothing changes in play.
- If it happens to you, please send **every** player's `boot.log` from that match.
