**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## MULTIPLAYER pages on native code, PLAY without Python

- **MULTIPLAYER** (Uncharted 3 and Uncharted 2) is now built by the launcher's native code: the setup steps, the folders, IMPORT / RE-IMPORT / UPDATE and Cancel, the import's step, progress and state, and the storage switch. The import itself works as before; the online section is unchanged.
- **PLAY** starts the games with the launcher's own native game starter (`launcher\native\game_starter.exe`) instead of through Python. The games start as before.
