**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Game starter

The game starter now runs entirely on the launcher's native code. Nothing changes in how the games start or play.

- **Start sequence on native code:** finding and laying the update over the game, the preparation, the patches, the settings, starting the game with its log and freeze watchdog, and the Collection menu switching between games are all done by the launcher's native code, exactly as before.
- **Clearer errors:** when a start fails before the game opens, the log now shows a one-line reason instead of a Python traceback.
