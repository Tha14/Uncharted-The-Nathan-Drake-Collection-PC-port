**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Launcher updates

More of the launcher moves to its own native code. Nothing changes in how you use it.

- **Game update install on native code:** GAME UPDATE -> Install from .pkg, using an extracted update folder, and Install the game from .pkg now run in the launcher's native code, with the same checks and messages (missing files, a damaged bin.psarc, the wrong region, an encrypted PKG).
- **Check game files on native code:** the base game check runs in native code, and faster.
- **Cleaner updates:** updates no longer carry over Python's cache folders.
- **Starter rewritten:** `Uncharted Launcher.exe` and the helpers it starts the games through were rewritten; three unused helper modules were removed.
