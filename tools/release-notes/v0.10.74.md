**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## The launcher no longer runs on Python

- **Native launcher core**: everything behind the launcher window (pages, settings, PLAY, updates, tools, multiplayer status) now runs in the launcher's own C++ code. The window no longer starts a Python process.
- **Smaller package**: the bundled Python is now only used by the multiplayer imports, and no longer carries Tcl/Tk.
- **New wording**: the remaining messages, log lines and setting hints are reworded. The settings and buttons themselves are unchanged.
- **Slow-drive warning**: now reads e.g. "The game (E:\...) is on drive E: (USB, exFAT-formatted)."
