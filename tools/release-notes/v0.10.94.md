**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Launcher

- **Game and update from folders only**: "Install game from .pkg" and "Install update from .pkg" were removed. Choose your extracted game folder (SETUP step 1) and your extracted update 1.02 folder (SETUP step 2). PkgTool is no longer part of the package.
- **Uncharted 3 import, Game of the Year disc first**: when your PS3 folders include the Game of the Year disc, the import takes the DLC maps from the disc and does not need the separately installed DLC map packs. Without it, the DLC map packs are still read from RPCS3's `dev_hdd0/game` as before. The 1.19 update and the game data are needed either way.
- **Online settings**: the DNS Server field is now above the game's RPCN server.
