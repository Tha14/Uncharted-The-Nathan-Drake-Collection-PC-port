**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Uncharted 3 multiplayer crash fixes, and a smaller download

- **Second match no longer crashes:** from the second match on, the game could run out of memory in a small heap (`Allocation failed: 32768 bytes ... Wrapped Malloc`) and close. The multiplayer helper (build v7.98) no longer takes that memory from the game; your multiplayer image is relinked automatically.
- **No more mid-match closes on a game check:** a leftover developer check of the game (`Preupdate jobs still running!` in the log) ended matches; it now carries on as it does on the PS4.
- **Fat Talbot in character customization:** scrolling to Fat Talbot in the multiplayer character menu could crash the game; it no longer does.
- **Multiplayer import update fixed:** an update of the import could stop at the Airstrip wall emblems ("1 step(s) failed, first: wall-emblem", `ImportError ... copy_item_blob`). The step now prepares everything it needs itself (recipe 1.13.1); your next import update reruns it.
- **About 100 MB smaller download:** the package now carries only what the launcher and the games use: a small FFmpeg with just the decoders the games need (instead of the full one with its video encoders), only the Qt parts the launcher window loads, and no unused Python and Pillow modules.
