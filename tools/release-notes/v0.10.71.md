**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## Online section, PLAY checks and shortcuts on native code

- **RPCN online play** (Multiplayer tabs): the section is now native code too: the same fields, buttons, friends list and automatic sign-in. Your saved login keeps working.
- **PLAY**: the questions before a game starts (game without update 1.02, damaged update files, a slow USB or exFAT drive) and the message when a game ends (closed, froze or stopped, and why) now come from the launcher's native code. They read as before.
- **TOOLS -> Desktop shortcut / Game shortcuts** are made by the launcher's native code instead of PowerShell. The shortcuts are the same.
