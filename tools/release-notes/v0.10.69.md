**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.
## CONTROLS and LAUNCHER pages on native code

Two more pages move to the launcher's own native code. They look and work as before.

- **CONTROLS** is now built by the native code: mouse, controller, and the key, mouse and controller bindings. Click a slot and press a key, mouse button or controller button as before; right-click clears it; Escape cancels a controller slot. The controller button icons are drawn by the launcher window itself.
- **LAUNCHER** (update mode, update check, Check now) is now built by the native code.
- The rules for bindings (a key or button does one thing; Move and Look take a whole stick) moved to native code too.
