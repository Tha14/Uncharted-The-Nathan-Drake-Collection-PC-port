**Uncharted: The Nathan Drake Collection** unofficial PC port with the **Uncharted 3 multiplayer restoration** (beta).
Based on BilalReloaded's PC port (credits in the README).

**Already on 0.9.x or 0.10.x:** press **UPDATE** next to PLAY (or let it install by itself: LAUNCHER tab, Automatic). **New install:** extract the zip into an empty folder and start `Uncharted Launcher.exe`.

No game files are included. Everything game-derived is made on your PC from your own PS3 and PS4 copies.

## Changes

- **The import no longer downloads anything from a server.** It uses only the game files already on your PC. The community server is used for online play only. New setups need Uncharted 3's game data folder in RPCS3 (`BCES01670DATA2`, written when the game goes online in RPCS3): the import tells you if it's missing. Existing imports are not affected.
- **New launcher and game icon,** our own design, replacing the old one.
- The licence files now include BearSSL's notice, and the package readme states which parts are not under the GPL.
- After the update, the launcher refreshes some multiplayer files by itself (a few minutes): some recipe folders were tidied.

## Repository

- Contribution rules (`CONTRIBUTING.md`) and a pull request checklist: no game files, no keys, no copied game code, no server addresses, no money.
- Research files and older multiplayer builds are no longer part of the repository.
