# Contributing

Thank you for helping. The full guide (what to work on, how to fork, rebase and open a pull request) is in the
[README's Contributing section](README.md#contributing). This page holds the rules every pull request must follow.

## The rules that keep the project online

This is an unofficial, non-commercial fan project. It stays available only because it distributes nothing that
belongs to Sony Interactive Entertainment, Naughty Dog or Bluepoint Games. A pull request that breaks any of these
rules is closed, and its commits are removed from the history if they were merged by mistake.

1. **No game files or game-derived data.** No paks, textures, audio, models, text, fonts or images from the games,
   no converted or extracted files, no patched game images, and no tables or blobs copied out of either game's files
   or executables. If a fix needs game data, it must be made on the player's PC from their own copy, by code or a
   recipe step.
2. **No keys or secrets.** No encryption keys, signing keys, passwords, tokens or credentials, whether from the
   games, Sony, a server or anyone else.
3. **No code copied from the games.** Write your own code. Short instruction patterns that find or check the place a
   patch goes in the player's own copy are fine; whole functions or large byte arrays are not.
4. **No server addresses.** Don't put the community server's IP address or host names anywhere.
5. **Only code you may share.** Your own code, or code from a project whose license allows it here (compatible with
   the GNU GPL v2), with its credit and license notice kept.
6. **No money.** Don't add donation links, paid features, ads or anything sold in connection with this project.
7. **No decryption instructions.** Don't explain how to decrypt or dump games, or link to where to get them.

By contributing you agree that your contribution is licensed under the GNU GPL v2 or later, like the rest of the
project.
